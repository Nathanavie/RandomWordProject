# RandomWordProject

A small React app that fetches a random word, looks up its definition from the Merriam-Webster dictionary API, and challenges you to guess the word from its definition. A simpler predecessor to GuessTheWord.

## Stack

- React 16 (Create React App), class components
- Random Word API for word generation
- Merriam-Webster Collegiate Dictionary API for definitions

## Running locally

```bash
npm install
npm start
```

Then open http://localhost:3000. You will need your own Merriam-Webster API key for definitions to load.
